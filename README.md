# 🏭 订单动态成本诊断智能体
## —— 中小劳保企业数智会计系统

---

## 📋 项目简介

本系统是面向**中小劳保用品制造企业**的订单动态成本测算与诊断原型，用于演示生产订单的**累计成本、同期标准成本、差异分析、预警和预计利润**。金额由确定性规则计算；当前版本尚未接入大模型，不能把固定规则文案表述成大模型结论。未完工订单只输出累计成本、预计完工成本和预计利润，只有100%完工且会计已审批的订单才输出正式实际利润。

> 🏆 **参赛场景**：2026 年北京市大学生数智会计创新应用竞赛

**适配场景**：安全帽、防护手套、安全鞋、反光背心、护目镜、防护服等劳保产品生产企业。

## ✨ 核心功能亮点

### 1. 💰 动态成本三要素核算
| 成本项目 | 核算内容 |
|---------|---------|
| **直接材料** | 按BOM定额 × 采购价格，实时跟踪材料价格差异与用量差异 |
| **直接人工** | 按工艺路线工时 × 工资率，区分工资率差异与效率差异 |
| **制造费用** | 变动/固定费用分别归集；当前按录入的订单分摊额计算，跨订单费用池自动分配待后续实现 |

### 2. 📉 差异原因规则分析
- 价格差异：市场波动 / 采购策略 / 供应商议价
- 用量差异：工艺损耗 / 操作熟练度 / 返工返修
- 效率差异：工序瓶颈 / 设备故障 / 生产调度
- 费用差异：水电能耗 / 产能利用 / 车间管理

### 3. 🔔 多维规则预警引擎
| 预警类型 | 触发条件 | 阈值分级 |
|---------|---------|---------|
| **成本差异预警** | 单项成本差异率 | 关注(3%)/预警(8%)/严重(15%) |
| **利润率预警** | 订单毛利率水平 | 关注(15%)/预警(8%)/严重(3%) |
| **交期预警** | 剩余交付天数与完工率 | 临近交付+进度滞后 |
| **进度预警** | 时间进度与完工进度差 | 滞后10%/20%分级 |

### 4. 📄 原始单据结构化识别
支持 6 类财会原始单据的规则识别与结构化解析：
- 销售订单 / 采购订单 / 领料单 / 工时卡 / 制造费用单 / 产品入库单
- 格式：Excel(.xlsx)、CSV（支持 UTF-8/GB18030 常见编码）
- 自动检测或人工指定单据类型、汇总统计，并可登记到订单证据链
- 登记后的单据默认为“待人工复核”，不会自动进入正式成本

### 5. 🎯 完工进度动态推演
- 基于完工率推算预计完工单位成本
- 预测最终总成本与最终利润率
- 提前识别亏损订单并给出干预建议

## 🧪 财会核心算法说明

### 标准成本制定
```
直接材料标准成本 = Σ(单位产品材料用量标准 × 材料标准价格) × 订单数量
直接人工标准成本 = Σ(单位产品工时标准 × 标准工资率) × 订单数量
制造费用标准成本 = Σ(单位产品费用分配率标准) × 订单数量
```

### 差异分析公式
```
材料价格差异 = 实际用量 × (实际价格 - 标准价格)
材料数量差异 = (实际用量 - 标准用量) × 标准价格

工资率差异 = 实际工时 × (实际工资率 - 标准工资率)
人工效率差异 = (实际工时 - 标准工时) × 标准工资率

变动制造费用耗费差异 = 实际工时 × (实际分配率 - 标准分配率)
变动制造费用效率差异 = (实际工时 - 标准工时) × 标准分配率
```

未完工订单采用“截至当前标准成本”与累计实际成本比较：
```
截至当前标准成本 = 整单标准成本 × 当前完工率
同期成本差异 = 累计实际成本 - 截至当前标准成本
```
材料价格/用量差异和人工工资率/效率差异在明细中分别列示。若标准价格、数量或工时为0，系统改为提示标准缺失，不执行除零运算。

### 完工率动态推算
```
推算最终单位成本 = 实际单位成本 / 完工率
推算最终总成本 = 实际已发生成本 / 完工率
推算最终利润 = 订单销售额 - 推算最终总成本
```

上述结果属于管理预测。正式实际利润还必须满足：订单100%完工（或已交付）且会计状态为“会计已审批/正式输出”。

## 📞 常见问题

**Q: 数据保存在哪里？会丢失吗？**
A: 订单数据以 JSON 格式保存在 `data_storage/orders_data.json`。程序不再静默清空或覆盖损坏文件，但仍建议定期备份；生产环境应改用数据库。

**Q: 可以对接真实的 OCR 单据识别吗？**
A: 可以。目前 `data/document_parser.py` 是基于结构化 Excel/CSV 的解析，后续可扩展 OCR API（如百度/阿里 OCR）将扫描件转换为 DataFrame 后复用同一解析逻辑。

**Q: 如何替换为我们自己的产品和材料数据？**
A: 打开「数据管理」页面，参考基础数据库的字段格式；或直接修改 `data/sample_data.py` 中的 `MATERIALS_LIBRARY`、`PRODUCT_TEMPLATES` 等常量。

**Q: 云端部署的数据和本地数据如何同步？**
A: 目前方案是各自独立存储（演示用云端，生产用本地）。如需同步可对接同一数据库或使用对象存储共享 `orders_data.json`。
